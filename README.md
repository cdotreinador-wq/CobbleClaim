# CobbleClaim

Mod de claims para Minecraft 1.21.1 + Fabric, pensado para Cobblemon/Cobbleverse 1.7.42.

## Primeira versão
- Enxada de Claim (modelo de enxada de madeira)
- Seleção por dois pontos
- 10.000 blocos iniciais por jogador
- Proteção de quebra e interações
- Membros por `/claim add <jogador>` e `/claim remove <jogador>`
- `/claim info` e `/claim delete`
- Admin: `/claimadmin give <jogador> <quantidade>` e `/claimadmin blocks <jogador> <quantidade>`
- Persistência em `cobbleclaim.json`

## Próximos módulos
- GUI
- visualização da claim com partículas
- permissões individuais
- NPC de venda/entrega de blocos
- proteção avançada de pistões/explosões/itens especiais
- suporte a claims administrativas
